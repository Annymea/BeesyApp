## Status of the project

On pause

## Goal

The goal of this project was to develop a task tracker app for myself.

I had tested various apps but never found one that really helped me keep track of everything I wanted or needed to do, while also motivating me to actually get things done. This was especially true for tasks I needed to complete regularly.

That's why I wanted to create a skill-based task tracker that gamifies my everyday to-dos.

## What does the app do?

<img width="317" height="560" alt="Screenshot2Beesy" src="https://github.com/user-attachments/assets/6673656c-c7df-4229-909a-38f8a1744e32" />
<img width="306" height="562" alt="ScreenShotBeesy" src="https://github.com/user-attachments/assets/fa4442a6-e86e-4976-a9e0-b4129fa33c21" />

At the moment, you can only add, sort, and delete tasks. However, my vision for the app goes far beyond that.

I started implementing a skill system. The idea was to let users create skills, such as "Programming", and assign tasks to them.

Whenever a task is completed, the user earns experience points (XP) for the associated skill.

This was the main concept at the current stage of development.

In the future, I also wanted to implement projects and recurring tasks to help me better organize my everyday life and all the different projects I'm working on.

## Challenges

<img width="718" height="542" alt="ScreenshotBeesyEntwurf" src="https://github.com/user-attachments/assets/4a993968-6856-4329-8747-bed9de4aeda6" />

I had already worked on a Kotlin app before, so I was somewhat familiar with the language and how to structure an app.

However, that was about half a year ago, and I had relied heavily on AI while developing my first project.

Looking back, I realized that while AI helped me make progress quickly, I didn't learn or remember as much as I would have liked.

That's why I decided to take a different approach with Beesy and write the code myself.

This also meant that I had to learn Kotlin almost from scratch again, which turned out to be one of the biggest challenges.

## What did I learn?

This project helped me get back into programming with Kotlin and taught me more about how to organize a larger project.

I learned how to:

- Work with Kotlin to develop an app
- Structure my code and organize the different parts of an application
- Plan and organize a larger software project
- Approach development without relying on AI-generated code
    

## Why is the project on pause?

I still want to continue developing Beesy, and I have many ideas for how to expand it.

However, I decided to focus on Unity for now because I want to get into game development.

I would like to return to this project in the future.

## Use of AI

I intentionally developed this project without using AI.

For personal projects and learning purposes, I want to preserve the magic of programming and figure things out myself.
